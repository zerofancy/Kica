# Kica 0.1.4

本次发布目标：Android APK、Linux X86_64 DEB；实际数值版本均为 4。
Windows 元数据随源码升为 4，本次不构建或发布 Windows 安装包。
Android 通用 APK 含 arm64-v8a、armeabi-v7a、x86、x86_64 原生目录；更新服务仅声明支持的 ARM64/X86_64 目标，32 位进程继续手动更新。
已核对本次 APK 与线上 0.1.3 的签名证书一致。

## 更新说明

- 新增启动时自动检查更新，以及设置页中的手动检查与自动检查开关。
- Android 支持应用内下载、进度显示、摘要校验，并经用户确认交给系统安装器安装更新。
- Linux 更新包下载完成后移入系统下载目录，可选择稍后安装，或退出 Kica 后手动安装；不自动运行安装程序。
- 统一弹窗和菜单的模态状态管理，避免更新提示打断已有交互。
- 改善导航、页面状态恢复及前后台处理。

## 发布检查

- 使用项目签名配置构建 Android Release，核对包名、版本、实际 ABI 和旧版签名兼容性。
- 运行共享桌面及 Android host 测试、桌面测试、文件行数和空白检查。
- 使用 Linux DEB 打包任务，保留 `libsecret-tools` 依赖。
- 从最终安装包计算 SHA-512，先完成两个文件的 R2 上传和 READY 校验，再以一次分发提交发布。
- 发布前后查询目标更新序列，确认版本递增，回执和请求幂等状态仅在本地安全保存。

真实 Android 设备覆盖安装、返回手势以及真实桌面安装升级不属于已经完成的自动化验证；不自动安装或替换本机已有应用。
