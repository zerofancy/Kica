01 / 本次拟采用的方案

  1. 单击标签直接搜索；右键、长按或明确的“更多操作”按钮打开复制／屏蔽菜单。
  2. 详情页直接显示全部标签，自动换行，不再限制前 8 个；沿用详情页自身纵向滚动。
  3. 标签屏蔽为本机持久化规则，与现有分类屏蔽独立配置，任一规则命中即隐藏。
  4. 服务未返回标签时补查详情，只在存在标签屏蔽规则时启用；限制并发、缓存结果，明确区分“无标签”和“标签未知”。
需要重点 Review：在线搜索使用现有关键词接口，不承诺标签精确搜索；启用屏蔽后，为避免遗漏，未知标签的作品在核验完成前不显示封面与标题；核验失败保留提示及重试入口。历史／下载提供临时显示被隐藏作品的入口，保证仍可管理已有记录和任务。

本期不增加标签订阅、云端同步、本地全站漫画数据库、多标签组合搜索或标题屏蔽。分类交互本期保持现有行为，视觉上与标签分组，避免混淆。

02 / 现状与依据

  • DetailScreen.kt 的分类和标签点击回调为空；标签使用 take(8) 截断。

  • AppSettings.blockedCategories 与 CategoryBlock.kt 只处理分类。搜索结果目前在写入页面状态时过滤，解除屏蔽后无法仅靠重新过滤恢复已丢弃项目。

04 / 搜索语义与导航

“搜索此标签”表示把标签作为关键词进行在线搜索。结果可能匹配标题或其他字段；界面必须显示“以标签文字搜索，结果由服务返回”。本期不伪造精确标签搜索，也不在分页结果上做标签二次筛选来模拟全站精确查询。
  1. 点击标签时，使用去除首尾空白后的完整文本填入现有搜索框，清空分类筛选；不自动转换简繁、不添加特殊搜索语法。
  2. 搜索页增加来源标识“来自标签：xxx”，附上范围说明。用户编辑关键词并提交后变为普通关键词搜索，来源标识消失。
  3. 连续点击同一标签只压入一个搜索页；快速切换不同标签时以最后一个导航意图为准。旧请求不得覆盖新的关键词或分页结果。
  4. 搜索可继续分页、失败重试、点击作品进详情；返回时依次回到原搜索结果、原作品详情，恢复原详情的滚动位置与全部标签布局。
  5. 被屏蔽标签仍可搜索；屏蔽规则持续作用于结果。页面提示“部分结果可能被屏蔽”，提供管理入口；搜索动作本身不自动解除规则。

05 / 屏蔽匹配、作用范围与管理

匹配契约

新增 blockedTags: Set<String> = emptySet()，独立于 blockedCategories。标签键按 trim + lowercase 生成，比较完整标签，任一标签命中即可屏蔽；例如“科幻”不匹配“科幻冒险”，英文大小写视为同一标签。

本期不进行简繁、全半角或同义词转换，显示文本保留原样；“悬疑”与“懸疑”需分别加入。该规则与上游的简繁统一不同，管理界面明确提示，避免引入未经验证的转换依赖。

区域标签屏蔽行为
首页推荐、随机、发现榜单、搜索、收藏按分类 OR 标签规则过滤。分类目录本身仍只受分类屏蔽控制；不修改服务端收藏状态。
历史记录、下载列表默认按同一规则隐藏；显示“已隐藏 N 项”及“临时显示隐藏项”开关，被隐藏作品可带原因标记展开。开关只在当前页面有效，离开后重置。
下载任务与文件屏蔽仅影响默认展示，不删除文件、不暂停任务；临时显示后可继续暂停、恢复、取消或进入既有离线阅读入口。
已打开详情与阅读器不强制退出、不打断阅读；详情可解除屏蔽。从历史／下载主动显示隐藏项后，允许打开对应作品。

管理入口

  • 设置增加“屏蔽标签（N）”入口；详情标签菜单及过滤提示可打开同一个管理对话框。
  • 支持单条手动添加、搜索已有规则、移除规则、清空全部。输入按单个完整标签处理，不按逗号拆分；空输入禁用添加，重复输入提示“该标签已被屏蔽”。
  • 移除单条即时生效；“清空全部”弹出确认，说明只清空标签规则。输入筛选仅影响管理列表显示，不改变规则。
  • 所有变更保留其他设置，成功落盘后才反馈成功；设置流更新后，已加载的原始数据立即重新过滤。解除规则可恢复原项目和顺序，无需重新请求整页。
  • 规则保存在本机，重启保留；不上传、不按账号同步；退出登录不清空，与现有本机设置归属一致。清理网络／标签缓存不能删除屏蔽规则。

06 / 标签数据与缺失处理

原则：列表接口是否完整返回 tags 尚未验证，不能只给摘要增加空列表就宣称屏蔽已覆盖。数据必须表达“未知”和“已确认无标签”的区别。

  1. 摘要增加可缺省的标签字段，建议 tags: List<String>? = null：字段缺失／格式异常为未知，合法空数组为已确认无标签。保留列表返回的有效标签，详情转摘要时携带标签。
  2. 详情响应的标签作为权威数据：合法空数组确认无标签；缺字段／格式异常仍为未知。不同来源不以“未知”覆盖已知缓存；一次真实刷新所得权威标签可替换旧值。
  3. 新增轻量标签元数据缓存（作品 ID、标签 JSON、核验时间），通过共享仓库读写；持久化采用独立 SQLDelight 表及下一版迁移。已有历史、下载 JSON 缺字段时可继续解码，不丢记录。
  4. 标签屏蔽为空时不因本功能额外请求详情。已有分类规则先过滤；无需核验已被分类屏蔽的作品。
  5. 存在标签规则时，对当前已请求页／本地当前可见批次解析标签：优先使用有效元数据缓存，再使用列表有效标签；未知项按作品 ID 合并补查详情，全局最多 3 个并发，不请求章节或图片。
  6. 补查期间未知项不显示作品封面和标题，列表显示“正在核验标签”；已确认且未命中的项目可先展示，原始数据顺序保持稳定。
  7. 补查失败／离线未知项保持隐藏，提示“有 N 部作品标签未能核验”，支持重试；不能将失败保存为已确认无标签。历史／下载的临时显示入口仍可访问这些项目，并注明“标签未核验”。
  8. 缓存有效期 7 天、最多 2000 部作品，按最近使用淘汰。在线过期后重新核验；离线可使用旧标签并显示“使用缓存标签”提示，完全无缓存仍为未知。空标签也是可缓存结果。
  9. 同一页面失败不自动无限重试；手动重试或下一次页面加载才重试。页面退出、关键词变化时取消不再需要的请求；共享请求只在没有消费者后取消，旧响应不更新新页面状态。

这一设计增加的是标签缓存，不是上游完整漫画数据库。缓存可能与服务端新编辑的标签存在最多 7 天差异；屏蔽属于浏览偏好，不构成内容隔离保证。开发前用响应样本验证标签数组完整性；若发现接口只返回部分标签，该来源统一按未知处理。

07 / 分页、空态与返回约束

  • 各列表保存未过滤的已加载数据，展示结果由最新规则派生。原始页码和总页数沿用服务响应，不按过滤后数量重算，也不把缓存写成过滤后的子集。
  • 追加新页时复用已有作品的标签核验结果，只核验新增或数据变化的作品；加载指示、核验状态变化和追加结果不得使已有卡片短暂消失。筛选状态提示与作品共用同一滚动列表，避免提示栏高度变化带动视口移动，并保持当前首项及像素偏移。
  • 保留无限滚动加载。整页作品全部命中屏蔽规则时，在该页原始位置插入全宽特殊项：“已加载第 N 页，该页作品已全部被过滤”。特殊项参与列表布局与滚动，滚动接近末尾时继续自动加载后续页。
  • 每次只请求一个后续页；连续整页过滤时逐页插入提示项，不跳页、不并发重复请求。失败时停止自动加载并保留重试入口，重试仍请求同一页。未核验页和空页使用独立提示，不能冒充被过滤页；核验过程中暂停自动加载，解除规则后恢复作品并移除相应提示项。本地历史／下载也自动推进核验批次，无需点击下一页。
  • 管理入口显示可统计范围内的数量：只统计已加载数据，不冒充全站隐藏数量。未知项与确定命中项分别计数。
  • Android 返回键／返回手势和桌面 Esc 均通过 PlatformBackHandler：清空确认 → 管理对话框 → 标签操作菜单／选择器 → 搜索子页 → 原详情 → 上一级。只关闭当前最上层交互，一次不跨两层。
  • 界面返回与系统返回复用导航回调；根页面无可返回内容时不拦截退出。关闭菜单后焦点回到触发控件，键盘焦点可见，按钮具备标签名称和动作说明。
  • 详情、管理列表、标签选择器等溢出区域必须在桌面提供同状态、可拖动、仅实际可滚动时显示的滚动条；普通标签使用换行，不创建嵌套滚动区。
