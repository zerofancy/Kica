# UI 开发约束

## Android 系统返回

- 新增或修改子页面、对话框、抽屉、弹出菜单、浮层、全屏控件等交互时，必须同步设计并实现 Android 系统返回键与返回手势行为。
- 返回处理优先级必须为：关闭最上层临时交互，再返回上一个子页面，最后才在根页面执行系统默认退出。
- 临时交互显示时，使用 `PlatformBackHandler` 拦截返回并只关闭当前最上层交互，不得同时弹出页面导航栈。
- 子页面的界面返回按钮与系统返回必须复用同一个返回回调和导航状态，避免行为不一致。
- 根页面没有可关闭的临时交互且导航栈没有上一页时，不要拦截系统返回。
- 完成相关修改后，必须在 Android 端分别验证界面返回按钮、系统返回键或返回手势，以及多层页面和弹出交互的返回顺序。

## 桌面端 Esc 返回

- Android 返回逻辑对应的桌面交互必须复用 `PlatformBackHandler`，使 Esc 按键遵循相同的关闭弹出交互和返回子页面顺序。
- Esc 必须优先关闭最后显示且可返回的交互；根页面没有可返回内容时不应关闭应用。
- 完成相关修改后，必须验证 Esc 在多层页面及弹出交互中的处理优先级。
